## 🆘 TROUBLESHOOTING

### Problem: Styles not showing
**Solution:**
- Make sure you copied the `<style>` section at the top
- Paste in HTML mode (not visual editor)
- Clear browser cache and refresh

### Problem: Buttons not working
**Solution:**
- Update phone number in `tel:+19055550123` format
- Make sure `#products` anchor exists on page
- Test links after saving

### Problem: Layout looks broken
**Solution:**
- Copy ENTIRE HTML (don't miss opening/closing tags)
- Check that all `<div>` tags are properly closed
- Clear cache and hard refresh (Ctrl+Shift+R)

### Problem: Not ranking in Google
**Solution:**
- Wait 2-4 weeks for indexing
- Update phone and review count with real data
- Get more Google reviews (most important!)
- Build backlinks from local sites
