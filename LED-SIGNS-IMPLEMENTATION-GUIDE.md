## 🚨 Common Mistakes to Avoid

### ❌ DON'T:
1. **Use fake reviews** - Google will penalize you
2. **Keyword stuff** - Write naturally for humans
3. **Ignore mobile** - 70%+ traffic is mobile
4. **Skip images** - Visual content sells
5. **Use generic content** - Make it specific to YOUR business
6. **Forget to update** - Keep info current
7. **Ignore page speed** - Slow = lost sales

### ✅ DO:
1. **Use real customer reviews** - Authenticity wins
2. **Write conversationally** - 8th grade level
3. **Test on mobile first** - Then desktop
4. **Use high-quality images** - Professional photos
5. **Be specific** - Prices, timing, locations
6. **Update monthly** - Reviews, products, content
7. **Optimize speed** - Compress images, clean code

## 🆘 Troubleshooting

### Problem: Images not loading
**Solution:**
1. Check collection has image uploaded
2. Image should be 1920×1080 or larger
3. File size under 500KB (compress if needed)
4. Clear browser cache

### Problem: Phone link not working
**Solution:**
1. Check format: `tel:+19055550123` (no spaces, dashes, parentheses)
2. Test on actual mobile device
3. Verify number is correct

### Problem: CTAs not scrolling to products
**Solution:**
1. Make sure product grid has id or class
2. Check JavaScript is loading
3. Look for console errors (F12)

### Problem: Page loads slowly
**Solution:**
1. Compress all images (TinyPNG.com)
2. Use WebP format if possible
3. Enable lazy loading
4. Minify CSS
5. Remove unused Shopify apps

### Problem: Not ranking in Google
**Solution:**
1. Wait 2-4 weeks minimum
2. Build more backlinks
3. Get more reviews
4. Create supporting content
5. Share on social media
6. Submit sitemap to Google
