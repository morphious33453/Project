## How to Convert to PDF:

### Option 1: Browser Print
1. Open any HTML guide in your web browser
2. Press Ctrl+P (Windows) or Cmd+P (Mac)
3. Select "Save as PDF" as destination
4. Click "Save"

### Option 2: Online Converter
- Upload HTML file to html2pdf.com or similar service
- Download generated PDF

### Option 3: Command Line (wkhtmltopdf)
```bash
wkhtmltopdf guide-1-signage-compliance.html guide-1-signage-compliance.pdf
```
